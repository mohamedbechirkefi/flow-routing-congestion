## 3. Publication toolchain (zero cost)

Exploratory smoke result: pandoc's Typst template leaves the font list empty by default and typst then fails with `font fallback list must not be empty`; passing `-V mainfont="New Computer Modern"` (a font embedded in typst) fixed it and a one-page PDF compiled. This is a toolchain check only, not a research result.

## 4. Compute budget (planning estimate, to be measured at M2)

The networks are tiny: the Braess network has 4 nodes and 5 links; a 6 by 6 bidirectional grid has 36 nodes and 120 directed links. Each Frank-Wolfe iteration costs one shortest-path tree per origin. The full proposed matrix (`research/protocol.md` section 8) needs on the order of 10^3 to 10^4 assignment solves. A planning guess of under one second per solve in pure Python with NumPy would put the full matrix well under a few hours on one core. This guess is not a measurement; M2 must time the smoke matrix and the owner may cut EXP-005 if the measured cost is higher.

## 8. Risks

1. **Solver convergence.** Frank-Wolfe converges slowly near equilibrium; an unconverged UE could overstate or understate the UE-SO gap. Mitigation: relative-gap stopping rule, tolerance sensitivity (S1), MSA differential check.
2. **Mixed compliance arm (EXP-004)** has no closed form and its fixed-point may converge poorly. Mitigation: defined as fixed compliant flow plus UE of the rest (convex for the followers); report non-convergence.
3. **Demand calibration** relative to free-flow loading may create artefacts. Mitigation: sensitivity S3 with an absolute calibration.
4. **Scope creep in the demo.** Mitigation: precomputed published results plus a small sandbox (Braess and 3 by 3 grid).
5. **Rights.** None identified for the synthetic design. TNTP data carry no licence file and are not used.
