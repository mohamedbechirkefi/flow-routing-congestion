Append-only. Each entry: id, date, decision, context, alternatives, rationale, decided by, consequences.

## D-001 (2026-11-24): Licence is the owner's protective non-commercial licence, not a permissive licence

- **Decision.** All original material in this repository is licensed under the FLOW Source-Available Non-Commercial Research License v1.0 (SPDX `LicenseRef-FLOW-NC-Research-1.0`), with a Contributor License Agreement (CLA v1.0).
- **Context.** Section 2 of `master_prompt.md` asks for an "owner-approved permissive code license". On 2026-11-24 the owner chose this protective licence instead, for their own protection. The licence package (`LICENSE`, `NOTICE.md`, `LICENSE_HISTORY.md`, `CLA.md`, `CONTRIBUTING.md`, `.github/CODEOWNERS`, `.github/workflows/cla.yml`) was committed at the first commit.
- **Alternatives.** A permissive licence (MIT, Apache-2.0, BSD) as the master prompt suggests.
- **Rationale.** The owner's decision. The master prompt gives the owner final authority, and the licence choice is the owner's to make.
- **Decided by.** The owner.
- **Consequences.** The project is source-available, not OSI open source; public texts must not call it "open-source". Third-party data and dependencies keep their own licences, recorded in `data/manifest.json` and the lockfile. New files carry the SPDX header where the format allows.

## D-002 (2026-11-24): Zero-cost publication toolchain is pandoc to Typst, no TeX

- **Decision.** Markdown is the canonical source. PDFs are produced by `pandoc` (3.6.3) converting Markdown to Typst, then compiled with the `typst` Python package (0.15.0). `manuscript.tex` is generated from Markdown by pandoc as a source artifact but is not compiled locally.
- **Context.** No TeX distribution is installed (`tex`, `pdflatex`, `xelatex` not found, see `progress.md`). Installing one is possible at zero cost but heavy; Homebrew on this machine is known to be unreliable.
- **Alternatives.** Install TeX Live or Tectonic; Chrome headless HTML to PDF.
- **Rationale.** Free, already installed, small, scriptable from Python. An exploratory smoke conversion succeeded this session (`progress.md`).
- **Decided by.** Proposed by the assistant per the session brief; the owner may revisit.
- **Consequences.** Never claim a LaTeX-compiled PDF. Typst output is inspected visually at M6.

## D-003 (2026-11-24): No external dataset is required; all networks are synthetic

- **Decision.** The study uses only synthetic networks: the Braess network, defined from the published example (equations, not copied files), and seeded random grids generated by the project's code.
- **Context.** Section 10 asks for "a synthetic Braess network and grid". The TransportationNetworks repository (TNTP format) carries no licence file and restricts use to "academic research purposes only" (see `data/manifest.json`).
- **Alternatives.** Download TNTP networks (Braess-Example, Sioux Falls) as fixtures or real-network extensions.
- **Rationale.** Removes all data-rights risk and keeps the project offline. Mathematical facts (cost functions and demand of the Braess example) are not data files and are re-entered from the cited paper.
- **Decided by.** Proposed by the assistant; owner confirmation requested (blocker list in `roadmap.md`).
- **Consequences.** No real-network claims of any kind. TNTP files are not downloaded, bundled or redistributed.

## D-004 (2026-11-24): Draft primary contrast and metric (awaiting owner freeze)

- **Decision (draft).** Primary metric: relative excess total system travel time over the system optimum, `R(arm) = TSTT(arm) / TSTT(SO) - 1`. Primary hypothesis concerns the user-equilibrium arm on grids. The free-flow shortest-path arm (FF) is the simplest baseline and appears in every comparison.
- **Context.** Section 10 asks for "the simplest baseline as the primary comparator". The research question ("can individually optimal routing worsen collective travel time?") is defined relative to the collective optimum, so SO is the natural normalising reference.
- **Alternatives.** (a) Make UE versus FF the primary paired contrast; (b) primary metric raw TSTT difference in vehicle-minutes per hour.
- **Rationale.** A dimensionless ratio is comparable across grid sizes and demand levels and matches the price-of-anarchy literature (Roughgarden and Tardos 2002).
- **Decided by.** Proposal only. The owner decides at the freeze (G-FREEZE).
- **Consequences.** If the owner prefers (a), the primary hypothesis in `research/protocol.md` section 4 changes before freezing.
