# results/

Machine-readable results, written only by the experiment runner.

- `results/exploratory/`: EXPLORATORY runs on seeds 9000-9019 (M2 planning measurements). Not findings, not evidence for any registered hypothesis. Each run directory holds `config.json`, `results.json` (schema `flow.result/1.0.0`), `metrics.csv`, `run_manifest.json` and, where generated, `report.md`, `report.pdf` and `figures/`.
- `results/raw/`: confirmatory outputs after the owner's freeze. Git-ignored and regenerated by script. Empty: no confirmatory run exists.
